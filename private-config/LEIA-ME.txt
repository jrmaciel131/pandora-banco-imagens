PASTA PRIVADA — NÃO ACESSÍVEL VIA WEB
======================================

Este diretório (private-config/) DEVE ficar ACIMA do document root no
servidor, ou seja, FORA da pasta dominio.com/.

Estrutura esperada no servidor DreamHost:

    /home/SEU_USUARIO/                                  ← raiz da conta
    ├── private-config/                                 ← ESTA pasta (privada)
    │   ├── config.php                  # credenciais, bases, hashes
    │   ├── google-credentials.json     # service account Google
    │   ├── passwords.json              # overrides de senha
    │   ├── users_override.json         # criado dinamicamente
    │   ├── .token_cache.json           # criado dinamicamente
    │   ├── lib/                        # bibliotecas PHP
    │   │   ├── db.php                  # camada de banco (PDO)
    │   │   └── google.php              # integração Sheets/Drive
    │   └── sessions/                   # gravadas pelo PHP em runtime
    │
    └── dominio.com/            ← document root público
        ├── .htaccess
        ├── 404.html  403.html  500.html
        ├── index.html
        ├── api/
        │   ├── handler.php             # ÚNICO endpoint público
        │   ├── cron.php                # cache warmer (CLI ou URL)
        │   └── .htaccess               # bloqueia .php que não seja handler/cron
        ├── thumbs/                     ← cache de imagens (PH)
        └── thumbs-po/                  ← cache de imagens (PO)

Como tudo isto fica ACIMA do document root, é fisicamente inacessível
via HTTP — não depende de .htaccess para proteção.

PERMISSÕES RECOMENDADAS NO SERVIDOR:
    chmod 700 private-config
    chmod 700 private-config/sessions
    chmod 700 private-config/lib
    chmod 600 private-config/*.json
    chmod 600 private-config/config.php
    chmod 600 private-config/lib/*.php

LEMBRETE — como ler chmod:
    cada dígito = dono | grupo | outros
    cada um soma:  r=4  +  w=2  +  x=1
    7 = rwx (ler, escrever, entrar)   — só pasta precisa do "x"
    6 = rw- (ler e escrever)          — arquivo PHP não precisa do "x"
    0 = --- (sem acesso)
    700 = só o dono entra na pasta
    600 = só o dono lê/edita o arquivo
    Em hospedagem compartilhada (DreamHost), isso impede que outros
    usuários do mesmo servidor leiam suas credenciais via filesystem.

CRON DO DREAMHOST (CLI):
    /usr/local/php83/bin/php /home/SEU_USUARIO/dominio.com/api/cron.php
